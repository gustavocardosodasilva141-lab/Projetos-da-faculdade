# Projetos da Faculdade

Repositório destinado a reunir e organizar projetos desenvolvidos durante a graduação em **Análise e Desenvolvimento de Sistemas (ADS)**.

## Objetivo

Centralizar atividades acadêmicas, exercícios e projetos práticos em um único lugar, facilitando a consulta e a evolução dos trabalhos.

## Organização

Cada projeto poderá ter sua própria pasta, com:
- código-fonte;
- instruções para execução;
- tecnologias utilizadas;
- descrição do problema e da solução.
